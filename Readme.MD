# Neurocommenting Bot

Telegram-бот для автоматического комментирования постов в каналах и группах с помощью ИИ. Управляется через Telegram-интерфейс, поддерживает несколько рабочих аккаунтов одновременно.

---

## Что умеет бот

### Управление ботом
- Список администраторов — кто может управлять ботом — настраивается через меню **Администраторы бота 👥**
- Общий SOCKS5 прокси для всех подключений — задаётся через меню **Общий прокси 🌐**
- Сервисный канал для уведомлений о комментариях и ошибках
- При подключении к Telegram бот пишет всем админам и в сервисный канал, что готов к работе — со списком подключённых аккаунтов и статусами их функций
- Устойчивый старт: если сети ещё нет (например, сервер только включился), бот ждёт её появления до 3 минут и делает до 3 попыток подключения на каждый аккаунт; если не подключился никто — завершается с ошибкой, и systemd поднимает его заново
- Токен AI и Agent ID — хранятся на сервере, меняются через меню
- Поддержка нескольких управляющих ботов

### Управление аккаунтами
- Подключение неограниченного числа Telegram-аккаунтов по номеру телефона
- Главное меню каждого аккаунта показывает статусы всех функций: сколько каналов подключено, включены ли автолайки, автоответы, рассылка и аутрич
- Редактирование профиля аккаунта: имя, фамилия, фото, описание, юзернейм
- Настройка индивидуального SOCKS5 прокси для каждого аккаунта
- Удаление аккаунта

### Нейрокомментинг ⚙️
- Автоматически комментирует новые посты в указанных каналах и группах
- Генерирует уникальные комментарии через ИИ (ChatGPT-совместимый API)
- Режим **"Комментировать первым"**: занимает место placeholder-сообщением, затем редактирует его готовым текстом
- Режим **"Шаблонные комментарии"**: вместо ИИ выбирает случайный текст из заданного списка
- Настройки (в подменю **Нейрокомментинг ⚙️** каждого аккаунта):
  - **Роль** — системная роль для ИИ (например: "Вы — маркетолог")
  - **Промпт** — задание для ИИ (например: "Напиши короткий комментарий на тему этого поста")
  - **Задержка** — пауза в секундах перед комментарием после выхода поста
  - **Шанс** — вероятность оставить комментарий (1 к N)
  - **Мин. символов** — минимальная длина поста; более короткие посты пропускаются
  - **Каналы** — добавить/удалить каналы для мониторинга (бот автоматически вступает при добавлении)

### Автолайки 👍
- Рабочие аккаунты автоматически ставят реакции на новые посты в каналах и на новые сообщения в чатах
- Список чатов и каналов для лайков свой, независимый от нейрокомментинга — можно одним нажатием перенести туда каналы комментинга
- При добавлении аккаунт сам вступает в канал или чат
- Реакция выбирается случайно из заданного списка (по умолчанию 👍 ❤️ 🔥 🥰 👏)
- Если в чате разрешены только определённые реакции, бот сам подберёт разрешённую
- Свои и сервисные сообщения игнорируются
- Настройки (в подменю **Автолайки 👍** каждого аккаунта):
  - **Реакции** — список эмодзи через пробел или запятую
  - **Задержка** — пауза в секундах перед лайком
  - **Шанс** — вероятность поставить лайк (1 к N)
  - **Большая реакция** — показывать реакцию увеличенной анимацией
  - **Уведомления** — писать о каждом лайке в сервисный канал (по умолчанию выключено, чтобы не засорять канал)
  - **Чаты и каналы** — добавить/удалить/очистить список для лайков

### Автоответы 💬
- Автоматически отвечает на входящие личные сообщения воркеру
- Включаются и отключаются кнопкой в шапке раздела **Автоответы 💬**
- На входящие сообщения от Telegram-ботов не отвечает
- Два режима:
  - **Статичный текст** — всегда отвечает одним и тем же заранее заданным сообщением
  - **ИИ-диалог** — ведёт полноценный диалог: отдельная роль и промпт, история переписки с каждым пользователем, настраиваемый лимит раундов

### Аутрич в ЛС 📨
- Воркер отслеживает указанные группы и автоматически пишет в личку всем, кто там пишет
- Никогда не пишет одному человеку дважды (дедупликация по всей истории)
- Настройки: текст сообщения, лимит DM в день, задержка перед отправкой, список групп для мониторинга
- При достижении дневного лимита останавливается до следующего дня

### Парсинг аудитории 💬
- Парсит всех пользователей, оставивших комментарии в указанном канале
- Результат — один CSV-файл с колонками: **ID, Username, Имя, Описание, Комментарии**
- Пользователи отсортированы по количеству комментариев — самые активные вверху
- Разделитель `;`, кодировка UTF-8 (открывается в Excel без настроек)
- Запускается через главное меню → **Спарсить юзеров в комментах 💬**
- Парсинг можно прервать досрочно командой `/finish`

### Инвайтинг 🦁
- Массовое добавление пользователей в группу с настраиваемым интервалом между приглашениями

### Рассылка по ЛС 🌪
- Массовая отправка сообщений по заданному списку пользователей

### Рассылка в чаты 📢
- Воркер рассылает заданный текст в список чатов в течение дня со случайными интервалами
- Работает только с **10:00 до 18:00 МСК** — вне окна засыпает до следующего утра
- Интервал задаётся в формате `мин-макс` секунд (например `600-1500` — от 10 до 25 минут)
- Включается и отключается кнопкой в шапке раздела **Рассылка в чаты 📢**
- После каждой успешной отправки приходит уведомление в сервисный канал

## Монитор 📊

Отдельный процесс `monitor.py`, который показывает состояние бота **локально и не завися от Telegram** — именно тогда, когда Telegram и есть то, что отвалилось. Бот сам ничего не отдаёт по сети: он раз в 30 секунд атомарно пишет `state.json`, а монитор читает его, спрашивает systemd и сам проверяет связь.

### Запуск

```bash
python monitor.py              # снимок в терминале
python monitor.py --watch      # живое обновление
python monitor.py --web        # страница на http://127.0.0.1:8787
python monitor.py --watchdog    # одна проверка, для systemd timer
python monitor.py --json        # снимок в JSON, для скриптов
```

Код возврата снимка: `0` — всё в порядке, `1` — есть проблема (удобно в `cron` и скриптах).

### Что показывает

- **Процесс** — что думает systemd, pid, uptime, сколько было рестартов, свежесть heartbeat
- **Клиенты** — подключён ли каждый аккаунт, его DC, прокси, когда Telegram последний раз ответил на RPC
- **Связь** — три независимых проверки: интернет в обход Telegram (`1.1.1.1`, `8.8.8.8`), DNS, TCP до трёх DC. Если задан SOCKS5-прокси, Telegram проверяется **через него** рукопожатием, иначе картина была бы ложной
- **Маршрут** — через какой интерфейс и адрес сейчас идёт трафик до Telegram. Это описание факта, а не условие: туннель, Wi-Fi, модем — монитор просто показывает, что есть сейчас
- **Процессы** — какие рассылки крутятся, идёт ли парсинг, сколько asyncio-задач
- **Статистика** — из таблицы `events`: за сегодня, за 7 дней с графиком по дням, ошибки и последние из них

Диагноз сводится к одной строке и различает: нет интернета / Telegram недоступен / бот не запущен / бот завис / работает через прокси / всё работает.

### Кнопки на странице

**Перезапустить** работает без каких-либо прав: монитор посылает SIGTERM процессу бота (он принадлежит тому же пользователю), а systemd поднимает его заново по `Restart=always`.

**Запустить** и **Остановить** управляют юнитом и потому требуют прав. Без них кнопки честно сообщают, что нужно правило. Чтобы они работали, добавь файл `/etc/sudoers.d/combot`:

```
gg-ai ALL=(root) NOPASSWD: /usr/bin/systemctl restart com, /usr/bin/systemctl start com, /usr/bin/systemctl stop com
```

Страница слушает только `127.0.0.1`, чтение открыто, а действия требуют токен из самой страницы и проверку `Origin` — иначе любой сайт в браузере смог бы послать POST на localhost. Снаружи смотреть — через SSH-туннель: `ssh -L 8787:127.0.0.1:8787 user@host`.

### Вотчдог

Раз в минуту проверяет состояние и перезапускает бота, **только если связь есть, а бот её не использует** — то есть не дёргает его, когда проблема в сети. Защита от цикла: не чаще одного перезапуска в 10 минут и максимум 3 подряд, дальше только уведомления.

Уведомления: строка в `monitor.log` плюс `notify-send` на рабочий стол. На голом VDS без графической сессии `notify-send` просто пропускается, лог остаётся.

### Установка

Локально, без прав root, пользовательскими юнитами:

```bash
mkdir -p ~/.config/systemd/user
cp systemd/combot-monitor.service systemd/combot-watchdog.service systemd/combot-watchdog.timer ~/.config/systemd/user/
# поправь в них пути на свои
systemctl --user daemon-reload
systemctl --user enable --now combot-monitor.service combot-watchdog.timer
loginctl enable-linger $USER     # чтобы работали и без входа в систему
```

На VDS — системными юнитами от root:

```bash
cp systemd/combot-*.service systemd/combot-*.timer /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now combot-monitor combot-watchdog.timer
```

Файлы монитора рядом с `app.py`: `state.json` (состояние), `monitor.log` (действия и инциденты), `watchdog.json` (история перезапусков). Все три в `.gitignore`.

## Развёртывание на VDS

### 1. Создай VPS

На любом VPS-хостинге → создай сервер:
- ОС: Ubuntu 22.04
- Тариф: минимальный (1 CPU, 1 GB RAM хватает для 5–10 аккаунтов)
- Запомни IP и пароль root

### 2. Подключись по SSH

```bash
ssh root@<IP_СЕРВЕРА>
```

### 3. Установи зависимости

```bash
apt update && apt install python3 python3-pip python3-venv git -y
```

### 4. Склонируй репозиторий

```bash
git clone https://github.com/Geliorn/neurocommenting-bot /root/ComBot
cd /root/ComBot
```

### 5. Создай виртуальное окружение и установи библиотеки

```bash
python3 -m venv venv
source venv/bin/activate
pip install requests xlsxwriter tgcrypto
pip install "git+https://github.com/KurimuzonAkuma/pyrogram.git@dev"
```

> Используется форк Pyrogram от KurimuzonAkuma — он поддерживает актуальные функции Telegram API.
> `tgcrypto` — опциональная C-библиотека для ускорения MTProto-шифрования. Без неё бот работает, но медленнее.

### 6. Получи Telegram API credentials

Зайди на [my.telegram.org](https://my.telegram.org) → API development tools → создай приложение. Запомни `api_id` и `api_hash`.

### 7. Создай управляющего бота

Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → задай имя и username. Получи токен вида `123456789:AAxxxxx...`.

Чтобы узнать `BOT_ID` (числовой ID бота) — возьми числовую часть токена до двоеточия: `123456789`.

### 8. Получи AI credentials (например в Timeweb)

Зарегистрируйся у AI-провайдера с ChatGPT-совместимым API:
- Создай AI-агента и скопируй **Agent Access ID** (`AI_AGENT_ID`)
- В настройках профиля создай **Bearer-токен** (`AI_TOKEN`)

### 9. Настрой конфигурацию

Скопируй пример конфига и заполни своими данными:

```bash
cp config.example.py config.py
nano config.py
```

Содержимое `config.py`:

```python
# Telegram App (my.telegram.org)
API_ID = 12345678
API_HASH = 'your_api_hash_here'

# Управляющий бот (@BotFather)
BOT_ID = 123456789
BOT_LINK = 'your_bot_username'        # без @
BOT_TOKEN = '123456789:AAxxxxxxxx...'

# Telegram ID администраторов бота
ADMINS = (123456789,)                 # твой Telegram ID, можно несколько через запятую

# AI API
AI_TOKEN = 'eyJ...'
AI_AGENT_ID = 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx'
```

> `config.py` не попадает в git — он в `.gitignore`.

Узнать свой Telegram ID можно через [@userinfobot](https://t.me/userinfobot).

### 10. Настрой автозапуск через systemd

```bash
cp systemd/com.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable com
systemctl start com
```

### 11. Проверь запуск

```bash
systemctl status com
```

Логи в реальном времени:

```bash
journalctl -u com -f
```

## Первый запуск

1. Напиши своему боту `/start` в Telegram — должно появиться главное меню
2. Нажми **"Добавить аккаунт"** и следуй инструкции:
   - Введи номер телефона в международном формате (`+79001234567`)
   - Введи код подтверждения из Telegram
   - Если включена двухфакторная аутентификация — введи пароль
3. После добавления аккаунт появится в разделе **"Мои аккаунты"**
4. Зайди в настройки аккаунта → **Нейрокомментинг ⚙️** и настрой:
   - **Роль** — кем представляется ИИ
   - **Промпт** — что именно писать в комментариях
   - **Задержку** и **шанс** по желанию
5. Там же нажми **"Добавить каналы 💬"** и отправь ссылки на каналы/группы, каждую с новой строки
6. Бот начнёт автоматически комментировать новые посты

## Частые вопросы

**Бот запустился, но не комментирует**
- Убедись что добавил каналы через "Добавить каналы 💬" в настройках аккаунта
- Проверь что аккаунт вступил в канал (бот делает это автоматически при добавлении)
- Посмотри логи: `journalctl -u com -f`

**Бот запустился, но молчит и не отвечает на /start**
- Посмотри логи: `journalctl -u com -f`. Строка `Network is unreachable` или `Connection timed out` значит, что на машине не было сети в момент старта
- Бот ждёт сеть и повторяет подключение сам, а если не подключился ни один клиент — выходит с кодом 1, и systemd перезапускает его через `RestartSec`
- Проверить доступность Telegram: `curl -I https://api.telegram.org`. Если доступа нет — задай прокси в меню **Общий прокси 🌐** или полем `PROXY` в `config.py`
- Признак живого бота: у процесса есть установленные соединения — `ss -tnp | grep python`

**Ошибка при добавлении аккаунта**
- Номер должен быть в международном формате: `+79001234567`

**Бот не ставит лайки**
- Проверь, что автолайки включены: настройки аккаунта → **Автолайки 👍** → **Включить ✅**
- Чаты для лайков задаются отдельно от каналов комментинга: **Автолайки 👍** → **Чаты и каналы 🧿**
- Если нужно лайкать те же каналы, что и комментировать — нажми **Взять из нейрокомментинга 📥**
- В канале могут быть разрешены только отдельные реакции — бот подберёт разрешённую сам, но если реакции в канале отключены, лайков не будет

**Как добавить или удалить администратора**
- В меню бота → **Меню 🌴** → **Администраторы бота 👥** — список с кнопками удаления и кнопкой «Добавить ➕»
- Изменения применяются сразу, без рестарта
- При первом запуске список инициализируется из `config.py` (поле `ADMINS`)

**Как настроить прокси для аккаунта**
- В настройках аккаунта есть кнопка прокси
- Формат: `socks5:host:port` или `socks5:host:port:user:pass` для аутентифицированного

**Как настроить глобальный прокси (для всех подключений)**
- В `config.py` задай поле `PROXY`:
  ```python
  PROXY = 'socks5:45.145.57.238:10253'             # анонимный
  PROXY = 'socks5:45.145.57.238:10253:user:pass'   # с авторизацией
  ```
